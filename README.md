# IDS 400 Capstone Workbook

The built workbook for the experimental IDS 400 Senior Capstone course at CSU Monterey Bay, Spring 2027. It is served by GitHub Pages at https://romanf88-arch.github.io/ids400-workbook/2027sp/ and loaded inside a SCORM shell in the Canvas course.

This repository holds code and course wording only. Student work is saved in Canvas through SCORM and is never sent here.
